How Relay Works

  • The relay folder is shared via SyncThing with remote editors
  • Recorder role: pushes file lists, shadow recordings, and transcripts
  • Editor role: receives project structure and shadow files for editing
  • Shadow recordings are low-res proxies so editors can preview without full video files
