# Archive

This directory contains historical documentation that has been archived to reduce token bloat in active files.

## Purpose

- Preserve complete historical records
- Reduce size of frequently-read documentation files
- Maintain chronological organization for reference

## Archived Files

| File                      | Date Range   | Description                           |
| ------------------------- | ------------ | ------------------------------------- |
| `requirements-2025-q4.md` | Nov-Dec 2025 | Completed requirements (FR/NFR specs) |
| `changelog-2025-q4.md`    | Nov-Dec 2025 | Implementation history for Q4 2025    |

## Finding Historical Information

- **Completed requirements** → `requirements-2025-q4.md`
- **What was implemented when** → `changelog-2025-q4.md`
- **Current active work** → `../backlog.md` and `../changelog.md`

## Archive Policy

- Files are archived when they exceed ~2000 lines or ~25k tokens
- Content is moved quarterly or by major version milestones
- All content is preserved exactly (no summarization)
- Active files reference archived files in header notes
