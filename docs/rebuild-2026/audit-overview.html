Why this matters for the rebuild

All three share a shape: the failure and the success look identical. The API returns success: true. The class name is spelled correctly. The preview renders. Nothing errors, so nothing gets reported as a bug — it gets reported as a feeling.

That is the class of defect a rebuild must design against, and it is exactly what B475 asked for: architectural flaws, not bugs.

Why the repo went silent

The last commit is 16 April 2026. Four months of nothing. The archaeology found the reason, and it was not fatigue.

On 12 April 2026 — four days before the final commit — a complete rebuild specification was commissioned. Everything committed after that date was work on an application whose owner had already decided to replace it.

That specification is still in the repo, 2,423 lines across two files, never acted on. It should not be used as the build brief. Its opening instruction is “replicate what works faithfully — don't strip features — this is a well-engineered, mature application”, which is the opposite of what this audit was asked to find. It preserves all eleven tabs and the global config the audit finds structurally wrong; its eight “improvements” are cosmetic; and it was generated from 50 commits when the repo had 193 — never seeing the genesis era where the constraining decisions were made.

It remains the most complete feature inventory in existence. Mine it for that, and nothing else.

The plan: a season, not a sprint

Each build session doubles as a video, section by section. That makes the unit an episode — so every one must end in something demoable, and each carries a named decision that goes on camera.

  1. 00

    Before any code

    The audit, the North Star, David's live-usage narration — and the real blocker: there is no design system. Two generations of exploration produced four whole-app designs and thirteen mockups, and neither produced a token spec, type scale or component vocabulary. The measured result is 108 distinct container treatments across 181 instances.

  2. 01

    The spine

    Five episodes building the North Star sentence end to end: the watcher and queue with stable take ids · one API with three unprivileged clients · transcribe at queue time · the take bench · scoring instead of guessing. Ship it and use it for real before anything else starts.

  3. 02

    The pipeline joints

    FliHub stops being an island. Events out to Teletubby · assembly of many takes into one video · deterministic project truth for FliLaunch · one synchronisation model for Jan and Mary, replacing the three that grew independently.

  4. 03

    The tabs, judged one at a time

    Not ported — each gets a hearing against one test: does it raise videos-shipped-per-week, and does something else in the suite now own it better? Assets likely leaves for Van Dam, Thumbs for FliLaunch, and the dev scaffolding shipped in the product gets deleted.

Method, and what it does not establish

Twenty-seven agents across two workflows, plus direct work against the running application. Every architecture strand was adversarially verified by a second agent instructed to refute it.

That pass mattered. Every finding survived, but sub-claims were killed and counts moved in both directions — a claimed “320-line handler” was actually 21 lines, a measurement artefact; “69 RPC-shaped routes” could not be reproduced and became 45; “30 errors returned as HTTP 200” turned out to be at least 51. Two of the corrections were to the lead session's own claims, including an early hypothesis that seven socket listeners were dead. Six of the seven are emitted through a config-table indirection that literal grep cannot see.

Limits

This audit did not run the test suite, did not exercise the app through the UI beyond read-only screenshots, and did not test the multi-machine relay against Jan's or Mary's machines. Claims about runtime behaviour derived from source are marked as such in each report.

Three files were uncommitted in the working tree throughout — findings touching them are flagged as needing a re-check against a clean tree.
